# Outpatient Waiting Time Analysis | 医院门诊患者等待时间分析

## Project Overview | 项目简介

**English**

Analysed 973,835 outpatient appointment and consultation records extracted from Oracle databases using SQL and Python. The project focused on identifying abnormal waiting-time patterns, analysing outpatient service efficiency, and providing data-driven recommendations to support hospital workflow optimisation.

**中文**

基于医院Oracle数据库中的973,835条门诊预约与就诊记录，使用SQL和Python开展数据清洗、业务指标分析及数据可视化，重点分析患者等待时间异常、不同科室的就诊效率差异及潜在业务瓶颈，为医院门诊流程优化提供数据支持和改进建议。

## Data Privacy | 数据隐私说明

**English**

The original dataset contains confidential hospital records and cannot be released publicly. A small anonymised sample is provided for demonstration purposes only.

**中文**

本项目使用的原始数据包含医院内部敏感信息，出于数据隐私和保密要求，无法公开完整数据集。仓库中仅提供少量经过匿名化处理的示例数据，用于展示项目的数据结构与分析方法。

## Key Outcomes | 主要成果

**English**

- Analysed 973,835 real-world outpatient records using SQL and Python.
- Identified abnormal waiting-time records and investigated differences across outpatient workflows.
- Analysed key operational indicators, including patient waiting time and departmental service efficiency.
- Developed a structured data cleaning, analysis, and visualisation workflow.
- Produced data-driven recommendations to support outpatient scheduling and resource allocation decisions.

**中文**

- **大规模数据分析：** 使用SQL和Python分析973,835条真实门诊预约与就诊记录。
- **数据质量治理：** 识别异常等待时间记录，并结合不同科室的业务流程分析异常情况。
- **核心业务指标分析：** 围绕患者等待时长、预约准时率及科室就诊效率等指标，分析不同科室与时段的服务效率差异。
- **数据分析流程构建：** 完成从数据提取、清洗、探索性分析到数据可视化的完整分析流程。
- **业务优化建议：** 根据分析结果提出门诊排班、资源配置及就诊流程优化建议，为医院运营决策提供参考。
